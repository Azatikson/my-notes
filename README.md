# My Notes

Быстрые заметки с блочным редактором, без аккаунта и без сервера. Данные хранятся в браузере, экспортируются в файл.

## Возможности

- Блочный редактор на Quill:
- Заголовки, списки, чек-листы, цитаты, код, ссылки
- Инлайн-форматирование: жирный, курсив, подчёркнутый, зачёркнутый
- Slash-команды: `/h1`, `/todo`, `/code` и ещё 10 команд — форматирование без отрыва от клавиатуры
- Теги `#тег` с автоматическим извлечением и фильтрацией списка
- Закрепление заметок: важное всегда наверху
- Палитра команд `Ctrl+K`: новая заметка, экспорт, импорт, панели
- Быстрый переход `Ctrl+P`: поиск по всем заметкам с превью
- Автосохранение в IndexedDB через 400 мс после окончания ввода
- Экспорт в Markdown и JSON, импорт из JSON и Markdown
- Тёмная тема, три панели: список, редактор, контекст
- Сворачивание боковых панелей: фокус на тексте
- Undo при удалении: тост «Отменить» на 5 секунд
- Модалка горячих клавиш по клавише `?`

## Технологии

- Vanilla JavaScript (ES-модули, без сборки)
- Quill 2.0 — блочный редактор
- IndexedDB — хранение заметок
- Turndown — HTML → Markdown при экспорте
- marked — Markdown → HTML при импорте
- Lucide — иконки
- CSS с custom properties, тёмная тема, анимации через keyframes

Без npm, без node_modules, без фреймворков. Открыл `index.html` — работает.

## Зачем этот проект

Notion недоступен в России, а привычные заметочники требуют регистрации, синхронизации через чужой сервер и доверия к чужому облаку. При этом многие заметки — личные: черновики, дневники, идеи — и им не нужен шаринг, команды и workspace.

Я сделал инструмент для одного сценария: **записать мысль быстро и не думать о том, куда она уходит**.

Три вещи, которые отличают его от конкурентов:

1. **Ноль трения.** Открыл ссылку — сразу пишешь. Нет логина, нет онбординга, нет выбора workspace.
2. **Данные у тебя.** Заметки в IndexedDB браузера, экспорт в Markdown и JSON. Сервера нет вообще — нечего взламывать, нечего блокировать.
3. **Скорость важнее фич.** Палитра команд, slash-команды, горячие клавиши. Всё, что нужно, — на расстоянии одного нажатия.

## Продуктовые решения

Почему именно такой набор фич и такой интерфейс:

- **Никакой регистрации.** Целевой пользователь — тот, кто хочет записать мысль за 3 секунды. Форма логина убивает весь смысл. Вместо аккаунта — экспорт в файл: пользователь сам решает, где хранить бэкап.
- **Только тёмная тема.** Продукт позиционируется как инструмент, а не как документ. Linear, Arc, Raycast, Obsidian — все инструменты для тех, кто «в теме», выбирают тёмное. Светлая тема оставлена на потом, если будет запрос.
- **Три панели вместо дерева.** Notion требует, чтобы ты сначала придумал структуру. Но наш пользователь не хочет решать «это в Notes или в Work?». Поэтому плоский список + теги + поиск. Хочешь структуру — используй wiki-ссылки (скоро).
- **Slash-команды вместо тулбара.** Тулбар отвлекает и занимает место. `/h1` быстрее, чем движение мышью. Это язык, к которому привыкают за один день.
- **Автосохранение через 400 мс.** Не после каждой буквы (нагрузка на IndexedDB), не раз в минуту (страх потерять). 400 мс — золотая середина, незаметная для пользователя.
- **Индикатор-точка вместо «Сохранение...».** Точка в топбаре: серая → жёлтая (сохраняется) → зелёная (сохранено). Тихая, не отвлекает, но всегда видно, что данные в безопасности.

## Метрики продукта

Как я оценивал бы успех этого инструмента, если бы развивал его как продукт:

- **Activation.** Доля пользователей, которые создали хотя бы одну заметку и написали в неё больше 20 слов. Порог в 20 слов отделяет «попробовал и ушёл» от «начал пользоваться».
- **Time to first keystroke.** Время от открытия страницы до первого символа. У Notion — ~30 секунд с логином. У нас должно быть < 3 секунд.
- **Retention D7.** Возвращаются ли пользователи на 7-й день. Без аккаунтов отследить сложно, но можно через событие «открыл страницу с уже существующими заметками».
- **Экспорт в Markdown.** Ключевое целевое действие. Если пользователь экспортирует — он воспринимает инструмент как место для реальной работы, а не как игрушку.
- **Использование slash-команд.** Показывает, что интерфейс понятен и пользователи освоили быстрый ввод. Низкое использование — сигнал, что тулбар всё-таки нужен.

## Планы по развитию

- **Wiki-ссылки `[[...]]` и обратные ссылки.** Связи между заметками важнее папок. Правая панель уже готова под backlinks
- **Граф связей.** Визуализация заметок и их связей. Показывает «второй мозг» на одном экране
- **PWA.** Установка как нативное приложение, работа офлайн. В резюме звучит сильно, в использовании — удобно
- **File System Access API.** Сохранение прямо в файл на диске, как в VS Code. Хром-only, но это privacy-first история в действии
- **Импорт папки Markdown.** Обратная операция к экспорту, для переезда из Obsidian
- **Split view.** Две заметки рядом, полезно для ревью и сравнения
- **Публикация отдельной заметки.** Через URL-хэш с содержимым, без сервера
